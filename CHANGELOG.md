# Changelog

All notable changes to Agent Tren are listed here.

## [1.1.0] - 2026-11-16

First public release.

### Features
- Always-on-top widget with one card per Claude Code session: current action, to-do progress, latest messages.
- Live subagent cards under their session.
- Allow / Deny permission requests and answer Claude's questions from the widget.
- States for finished, interrupted (stop button) and usage limit / API errors.
- Sound, Windows notifications, tray menu, start with Windows, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd> shortcut.
- Snaps to any screen corner and never leaves the screen unless you drag it off.
- One-click connection to Claude Code with automatic settings backup.
- Event log for troubleshooting.
